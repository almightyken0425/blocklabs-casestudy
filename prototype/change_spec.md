# CoinMahjong 原型修改規格

本文件列出本次原型相對原始 HTML 的功能差異。
內容以已實作行為為準，供功能審查及後續修改使用。

## 比較基準

| 項目 | 基準 |
| --- | --- |
| 原始版本 | Git 提交 `1ef5442` 中的 `mahjong-game-standalone.html`。 |
| 修改版本 | 本工作區的[麻將原型](../mahjong-game-standalone.html)。 |
| 功能來源 | [CoinPoker 行為調查](../research/coinpoker_prototype_research.md)。 |
| 核對日期 | 2026-10-04。 |
| 完成程度 | 可操作的本機互動原型。會員及對手事件使用模擬資料。 |

原始版本已具備牌桌、手牌、棄牌、玩家資訊及中央計分區。
它也支援依網址載入桌型、三人桌、等待畫面及視窗縮放。
本次保留這些能力，新增玩家身分與社交互動。

## 修改總覽

| 功能區域 | 原始版本 | 本次修改 |
| --- | --- | --- |
| 玩家頭像 | 固定圖片。 | 可分組選取，立即套用並保存。 |
| 玩家外框 | 沒有外框展示配置。 | 每次載入隨機分配外框，同桌不重複。 |
| 桌上身分 | 右側列表及中央計分區顯示玩家。 | 桌上新增對應座位的頭像與名稱。 |
| 牌組排列 | 手牌與玩家身分未採一致的左右配置。 | 以各玩家視角將 avatar 放左、手牌靠右。 |
| 玩家資料 | 沒有點擊頭像的資料視窗。 | 可查看本人與對手的名稱、風位及會員身分。 |
| 一般表情 | 沒有入口或播放功能。 | 新增分類、最近使用及座位動畫。 |
| 指定投擲 | 沒有指定玩家的互動。 | 新增對手入口、目標回饋及飛行效果。 |
| 聊天 | 沒有聊天面板。 | 新增訊息歷史、送出及訊息操作。 |
| 聊天泡泡 | 沒有座位訊息提示。 | 新增限時泡泡及顯示設定。 |

| 自動操作開關 | 有 Auto-Pass 等靜態控制項。 | 可切換開關外觀，未增加牌局判定。 |

## A. 玩家身分、頭像與外框

### 入口與畫面

- 點視窗 header 右上角的 Settings 齒輪，開啟 Avatars 分頁。
- 桌面入口位於縮小與關閉按鈕旁，窄螢幕入口固定在牌桌右上角。
- 點玩家列表區的 Profile 按鈕，開啟對應玩家的資料視窗。按鈕位於東南西北風圖示左側，風位圖示保留。
- 右側玩家列、桌上座位及中央計分區使用同一頭像資料。
- 桌上本人名稱附有 You 標記。

四方 avatar 都放在該玩家視角的牌組左側，手牌靠右排列。
畫面下方的東風頭像在手牌左邊，上方的西風頭像在右邊。
畫面右方的南風頭像在手牌下方，左方的北風頭像在上方。
排列理由見[牌組安排決策](../decision_log.md#決策-2頭像放左側手牌靠右排列)。

頭像設定提供大型預覽、分類列及目前選取標記。
分類列可水平捲動，設定內容可垂直捲動。
3-BET CLUB 與 WORLD CUP 另有左右切換按鈕。

### 共用操作規則

- 有效座位才會出現在互動目標中。
- 三人桌不建立第四個座位的互動入口。
- 等待狀態保留已入座玩家的社交操作。
- 設定分頁及表情分類可用左右方向鍵切換。
- 對話視窗支援關閉按鈕及 Escape。
- 圖示按鈕提供可及名稱，鍵盤聚焦時有外框提示。
- 社交素材尚未載入時，主要社交入口暫停操作。
- 素材讀取失敗會顯示提示，重新載入頁面可重試。

### 窄螢幕與矮視窗

視窗寬度不大於 760 像素，或高度不大於 560 像素時，使用窄螢幕配置。
Settings 固定在牌桌右上角。
牌桌右下角以兩欄提供聊天、玩家及展示控制三個入口。
開啟 Players 後，點本人頭像開啟 Emotes，點對手頭像開啟 Throwables。
列表中的 Profile 按鈕與風位圖示分開呈現。

設定、表情選單及聊天面板按牌桌的可用尺寸限制大小。
窄螢幕聊天展開時覆蓋牌桌，歷史仍可捲動，關閉後回到牌桌。
牌桌本體仍使用原有等比縮放。
手機版沿用桌面排列及縮放，未獨立設計手牌操作。

畫面參考：[目前手機玩家列表](../verification/avatar_hover_mobile_players.png)。
