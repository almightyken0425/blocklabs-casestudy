# Questions 1 and 2: Prototype and Decision Log

This folder contains the existing work for assignment sections 1.1 and 1.2.
It extends the supplied Mahjong table with CoinPoker identity and social interactions.

- [Prototype](mahjong-game-standalone.html): interactive avatars, emotes, throwables, and chat.
- [Decision log](decision_log.md): product choices, rejected alternatives, and their rationale.
- [Operation guide](support/prototype/README.md): launch instructions, controls, and verification evidence.
- [Change specification](support/prototype/change_spec.md): implemented behavior relative to the supplied HTML.

The `support/` folder contains this prototype's code, assets, research, tests, and verification records.
Question 3 has a separate copy and can evolve independently.
