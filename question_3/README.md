# Question 3: What Comes Next

This folder is an independent starting point for assignment section 1.3.
The task is to propose a system to add or modify after the initial features succeed, explain its value, and assess whether CoinPoker should adopt it.

The [prototype](mahjong-game-standalone.html) is copied from the current Questions 1 and 2 implementation.
It currently has the same avatar, emote, throwable, and chat features. No new Question 3 system has been selected or implemented yet.

## Working on the New Prototype

- Edit `mahjong-game-standalone.html` and `support/prototype/` in this folder for Question 3 changes.
- This folder has its own assets, research, tests, and verification records under `support/`.
- Saved browser preferences use a separate key, so they do not affect Questions 1 and 2.
- The [baseline decision log](baseline_decision_log.md) preserves the inherited decisions. It is a reference for the starting point, not a decision log for the new proposal.
- The [operation guide](support/prototype/README.md), [change specification](support/prototype/change_spec.md), and existing screenshots describe the inherited baseline until updated for the new work.
